About This Module

UI/UX Design is the process of creating digital products that are both visually appealing and easy to use. In this module I am learning how to design interfaces using Figma — from initial wireframes to fully interactive prototypes.

Good UI/UX design is about understanding the user's needs and creating experiences that feel natural, intuitive, and enjoyable. I have completed 2 design projects in this module so far.

What I'm Learning

UI vs UX — understanding the difference
Figma basics — frames, components, auto layout
Wireframing — low and high fidelity
Prototyping — interactive screen flows
Color theory and typography in design
User-centered design principles
Mobile-first design approach

Smoothie Ordering App
Mobile App UI/UX Design · Figma Prototype
UI Design UX Design Figma Mobile App Prototyping

Designed a complete Smoothie ordering mobile app using Figma. The design focuses on a clean, fresh, and vibrant user interface that makes ordering smoothies simple and enjoyable.

The prototype includes interactive screens with smooth navigation flow — from the home screen, to product selection, customization, and checkout. Special attention was given to color choices, typography, and visual hierarchy to make the app feel premium and appetizing.

Red Bull — Brand UI Design
Brand Design · UI/UX · Figma Prototype
Brand Design UI Design Figma Prototyping Red Bull

Designed a Red Bull brand UI project using Figma, capturing the bold, energetic, and dynamic identity of the Red Bull brand. The design stays true to Red Bull's iconic color palette — deep blue, silver, and red — while creating a modern and engaging user interface.

This project helped me understand brand-consistent design, how to work with established visual identities, and how to create interfaces that reflect a brand's personality and energy.

My Reflection

UI/UX Design has been one of the most creative and exciting modules so far. Learning Figma opened up a whole new world of digital design for me — I now see every app and website differently, noticing design choices that I never paid attention to before.

Working on the Smoothie app and Red Bull brand design taught me how important color, typography, spacing, and visual hierarchy are in creating a great user experience. I am excited to keep improving my design skills!
