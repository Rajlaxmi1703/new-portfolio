🔼 Unary Operators

My Java Code
class UnaryOperator{
    public static void main(String[] args){
     int a = 5 , x, y;
     y = a++ ;
     System.out.println("After ++ : "+y);
     y = a-- ;
     System.out.println("After -- : "+y);
     x = ++a ;
     System.out.println("After ++a : "+x);
     x = --a ;
     System.out.println("After --a : "+x);
    }
}
Sample Output
After ++ : 5 After -- : 6 After ++a : 6 After --a : 5

Post-increment (a++) uses the value before adding 1, while pre-increment (++a) adds 1 first, then uses the new value.

💡 What I learned: The five main operator categories in Java — arithmetic for calculations, assignment as shortcuts, bitwise for binary logic, relational for comparisons, and unary for quick increment/decrement, including the difference between pre and post versions.

⏭️ break & continue

My Java Code
public class BreakANDContinue {
  public static void main(String[] args) {
    for (int i = 1; i <= 20; i++) {
      if (i == 8) {
        continue;
      }
      if (i == 20) {
       break;
      }
      System.out.println("i = " + i);
    }
  }
}

i = 8 is skipped by continue, and the loop stops completely before printing i = 20 because of break.

💡 What I learned: How different control flow tools fit different jobs — if/switch for decisions, for/while/do-while for repetition, and break/continue for controlling a loop's flow from inside. Also practised printing patterns using nested loops.

🎭 All 4 Pillars Together

My Java Code
abstract class Vehicle {                 // Abstraction
    private String name;                 // Encapsulation
    public Vehicle(String name) { this.name = name; }
    public String getName() { return name; }   // Getter
    abstract void start();               // no body here
    void start(String mode) {            // Overloading
        System.out.println(getName() + " starting: " + mode);
    }
}
class Car extends Vehicle {              // Inheritance
    public Car(String name) { super(name); }
    void start() {                       // Overriding
        System.out.println(getName() + " engine started");
    }
}
public class AllPillars {
    public static void main(String[] args) {
        Car c = new Car("Tesla");
        c.start();
        c.start("Sport");
    }
}
Sample Output
Tesla engine started Tesla starting: Sport

💡 What I learned: How all 4 pillars of OOP work together — encapsulation hides data behind getters/setters, inheritance lets a child class reuse a parent's behaviour via extends/super, polymorphism lets the same method act differently depending on the object (overloading and overriding), and abstraction hides implementation details behind abstract classes and interfaces.
